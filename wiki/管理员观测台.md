# 管理员观测台

管理员从独立入口登录。生产环境必须使用部署时配置的管理员身份，不能沿用开发环境示例密码。

![管理员登录页面](res/管理员登录.png)

## 用户账户

管理台列出用户账户，并支持：

- 刷新账户列表。
- 为指定用户设置新密码。
- 删除用户。

重置密码时管理员只设置新密码，不查看旧密码。删除用户前必须二次确认，并先核对是否涉及尚未交付的数据或退款处理。

## 批量生成兑换码

填写：

- 生成数量：1 至 1000。
- 每码 credits：大于 0，最多 10000。
- 过期时间：可选。

点击“批量生成”后，本批完整兑换码只应通过受控渠道交付。使用“复制全部”后应立即保存到内部业务系统，不要把兑换码提交到 Git、聊天群或公开文档。

## 兑换码状态

| 状态 | 含义 |
|---|---|
| `ACTIVE` | 可以兑换 |
| `REDEEMED` | 已被某个用户兑换 |
| `REVOKED` | 管理员已撤销 |
| `EXPIRED` | 已过期 |

活动兑换码可以撤销。已兑换码不能通过简单撤销自动追回用户余额；需要单独的财务和审计流程。

## 管理操作安全

1. 管理员入口不要暴露默认凭据。
2. 每个服务密钥必须不同。
3. 兑换码批次、用户删除和密码重置应保留服务端审计记录。
4. 管理页面报错时记录 traceId，不要反复执行破坏性操作。
