# 答题与智能复习

## 四种入口的区别

| 模式 | 选题方式 | 是否更新掌握度 |
|---|---|---|
| 章节练习 | 从所选章节的正式题库中取题 | 是 |
| 智能复习 | 先取 SM-2 已到期内容，再按图谱先修关系安排 | 是 |
| 模拟试卷 | 从已核对并绑定知识点的题目组卷 | 是 |
| 故事回响 | 把同一计划中的知识点放入剧情选择 | 是 |

## 自动判分

客观题使用确定性答案规则。主观题不会把一个“相似度百分比”直接当成正确率，也不会让用户手动选择 q 值。

主观题会把参考答案拆为必要事实，再判断用户答案对每个事实是蕴含、矛盾还是不确定：

- 必要事实全部覆盖且没有矛盾：判为正确。
- 只覆盖部分事实：判为部分正确。
- 存在关键反转或否定：判为错误。
- 模型缺失、低置信或证据冲突：自动拒判。

自动拒判不会扣分，不写入掌握度，也不要求用户自己对照答案。系统应跳过该次不可靠证据并继续流程。

## SM-2 和知识图谱怎样配合

两者不使用随意的百分比混合：

1. SM-2 根据既有复习记录确定哪些知识点已经到期。
2. 识网检查到期知识点是否依赖尚未掌握的先修项。
3. 有先修缺口时先复习先修点。
4. 同层内容按到期时间和遗忘次数稳定排序。

图谱不会直接修改 q、EF 或复习间隔；答题证据也不会改变图谱结构。

## 作答时的建议

- 名词解释应说明概念的主语、关系和关键条件，不必逐字复述。
- 简答题按要点分行，避免只写标题。
- 不确定时仍可按自己的理解作答，系统不要求自评。
- 提交后可展开“资料依据”，查看判断所依据的原文。

## 为什么提示没有可用题目

智能复习只会从本册计划与正式题库的交集取题。现在的实现会跳过个别缺题知识点并继续寻找后续覆盖项；只有整个计划都没有可练习题时才会阻止进入。此时应回到研习册恢复成题，而不是手工补签每一道题。
